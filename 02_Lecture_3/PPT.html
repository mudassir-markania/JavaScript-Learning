Homework Review

Answers: Part 1

1. Primitive vs Reference:

Primitives (like Strings) are stored directly in the Call Stack because they have a fixed size. Non-primitives (like Objects) are stored in the Memory Heap because they can grow dynamically. The Stack only holds a memory address (reference) pointing to the Heap.

2. The Dead Zone:

The Temporal Dead Zone (TDZ) is the period between when a let or const variable is hoisted to the top of its scope and when it is actually initialized. Accessing it during this time results in a ReferenceError: Cannot access variable before initialization.

Homework Review

Answers: Part 3

5. Hoisting Hero:

When you try to log a var variable before initialization, it prints undefined. It doesn't crash because JS "hoists" the variable declaration to the top of its scope and initializes it with undefined by default.

6. DevTools Debugger:

Using debugger; and F10 allows you to pause execution and step through line by line. In the Scope pane, you can visibly see variables move from being uninitialized (in the TDZ) or undefined, to having their actual values assigned!
