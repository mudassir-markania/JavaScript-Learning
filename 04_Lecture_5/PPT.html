Operators

Comparison (Equality)

Comparison operators always return a Boolean. JS has two equality operators:

  • ==  Loose equality — only checks value, converts types automatically.
  • ===  Strict equality — checks value AND type. Use this always!
  • != / !==  — loose / strict inequality.

console.log(5 == "5");   // true  — string coerced to number
console.log(5 === "5");  // false — number !== string

console.log(0 == false); // true  — both coerce to 0
console.log(0 === false);// false — different types

Operators

Relational Operators

Numeric comparison

  • > Greater than
  • < Less than
  • >= Greater or equal
  • <= Less or equal

String comparison

Compared alphabetically by Unicode value, character by character.

"B" > "A" → true


let age = 18;
console.log(age > 18);    // false (not strictly greater)
console.log(age >= 18);   // true
console.log("b" > "a");   // true  (Unicode: b=98 > a=97)

Operators

Logical Operators

  • && AND — true only when all conditions are true.
  • || OR   — true when at least one condition is true.
  • ! NOT — flips the boolean value.

let hasTicket = true;
let isVIP     = false;

console.log(hasTicket && isVIP); // false — both needed for AND
console.log(hasTicket || isVIP); // true  — one is enough for OR
console.log(!hasTicket);         // false — NOT flips true → false

// Real-world example: user must be 18+ AND have a valid ID
let canEnter = age >= 18 && hasID;

Control Flow

If / Else Statement

The most basic decision structure. If the condition is true → run Block A, otherwise → run Block B.


let hour = 14; // 2 PM in 24-hour format

if (hour < 12) {
    console.log("Good Morning! ☀️");
} else {
    console.log("Good Afternoon! 🌤️");
}

// Output: Good Afternoon! 🌤️

Tip: The curly braces {} are optional for single-line bodies, but always use them to avoid bugs!

Control Flow

Else If Ladder

Handles more than two possible outcomes. Conditions are checked top to bottom — the first true match wins, the rest are skipped.


let score = 85;

if (score >= 90) {
    console.log("Grade: A ⭐");
} else if (score >= 80) {
    console.log("Grade: B 👍");   // ← This runs
} else if (score >= 70) {
    console.log("Grade: C");
} else {
    console.log("Grade: F ❌");
}
// Output: Grade: B 👍

Control Flow

Nested If Else

An if statement placed inside another if block — used to check layered conditions (prerequisites).


let age   = 21;
let hasID = false;

if (age >= 18) {            // OUTER: old enough?
    if (hasID) {            // INNER: has valid ID?
        console.log("Welcome to the club! 🎉");
    } else {
        console.log("You need your ID card! 🪪");
    }
} else {
    console.log("You are too young to enter.");
}
// Output: You need your ID card! 🪪

Control Flow

Switch Statement

A clean alternative to a long else if chain when matching one variable against exact values. Uses strict === internally.

⚠️ Warning: Always add break! Without it, execution "falls through" into the next case automatically.


let day = "Monday";

switch (day) {
    case "Monday":
    case "Tuesday":
        console.log("Start of the week 💪"); break;
    case "Friday":
        console.log("Almost weekend! 🎉");   break;
    default:
        console.log("Mid-week grind");
}
// Output: Start of the week 💪

Control Flow

Ternary Operator ? :

The only JavaScript operator with three parts — a compact one-liner for simple if/else assignments.

condition  ?  valueIfTrue  :  valueIfFalse 


let age = 20;

// ❌ Verbose: 5 lines
let status;
if (age >= 18) { status = "Adult"; }
else           { status = "Minor"; }

// ✅ Compact: 1 line with ternary
let status = age >= 18 ? "Adult" : "Minor";

console.log(status); // "Adult"

Boss Challenge  1/3

The Truthy Trap

🧠 What gets logged? Think before you answer! (Hint: not all values behave like you expect inside if)


if ("0")  { console.log("A"); } else { console.log("B"); }
if (0)    { console.log("C"); } else { console.log("D"); }
if ("")   { console.log("E"); } else { console.log("F"); }
if ([])   { console.log("G"); } else { console.log("H"); }

Answer: A, D, F, G

Falsy values in JS: 0, "", null, undefined, NaN, false. Everything else (including "0" and []) is truthy!

Boss Challenge  2/3

The Missing Break

🧠 How many lines get logged to the console?


let signal = "Yellow";

switch (signal) {
    case "Red":
        console.log("Stop 🔴"); break;
    case "Yellow":
        console.log("Slow Down 🟡");
        // ← no break here!
    case "Green":
        console.log("Go 🟢"); break;
    default:
        console.log("Invalid signal");
}

Answer: 2 lines — "Slow Down 🟡" and "Go 🟢". When break is missing, JavaScript falls through and executes the next case automatically!

Boss Challenge  3/3

Operator Precedence

🧠 What is the final value of each variable? No running the code — think it through!


let a = true || false && false;   // What is a?
let b = (true || false) && false; // What is b?
let c = !true || true;            // What is c?

a = true — && runs first: false&&false = false, then true||false = true

b = false — parentheses force || first: true||false = true, then true&&false = false

c = true — ! runs first: !true = false, then false||true = true

Cinema Ticket System

🎬 A cinema charges tickets based on age. Read the code below carefully, then predict every single line that gets logged. No running it!


// Lectures 1 & 2: Variables & Data Types
const cinema   = "StarPlex";
let   rawAge   = "  17  ";          // user input from prompt()
let   isStudent = true;

// Lecture 3 & 4: Type conversion + String methods + Math
let age    = Number(rawAge.trim()); // convert and clean
let lucky  = Math.floor(Math.random() * 100) + 1;
let label  = age >= 18 ? "Adult" : "Minor";   // Lecture 5: Ternary

// Lecture 5: Logical operators + if/else chain
let price;
if (age < 5) {
    price = 0;
} else if (age < 13 || isStudent) {
    price = 8;
} else if (age >= 13 && age < 18) {
    price = 12;
} else {
    price = 18;
}

// Lecture 5: Switch for concession stand
let concession;
switch (true) {
    case price === 0:  concession = "Free popcorn! 🍿";  break;
    case price <= 12:  concession = "50% off snacks 🥤"; break;
    default:           concession = "Full price";
}

// Lecture 4: Template Literals
console.log(`Welcome to ${cinema}!`);
console.log(`Age: ${age} | Category: ${label}`);
console.log(`Ticket price: $${price}`);
console.log(`Concession: ${concession}`);
console.log(`Lucky number: ${lucky}`);

Expected Output:   Welcome to StarPlex!  |  Age: 17 | Category: Minor  |  Ticket price: $8  |  Concession: 50% off snacks 🥤  |  Lucky number: (random 1–100)

Why $8? Age 17 is <18 but isStudent = true, so the age < 13 || isStudent branch fires first!
