Browser Interactions

Alert Boxes

JavaScript provides three built-in functions to interact with the user via popup boxes in the browser:

1. alert()

Displays a message and waits for the user to press "OK".

alert("Welcome to Lecture 4!");

Browser Interactions

Prompt & Confirm

2. prompt()

Shows a message asking the user to input text. Returns the text, or null if canceled.

let age = prompt("How old are you?", 18);
console.log(age);
3. confirm()

Shows a message with "OK" and "Cancel". Returns true for OK and false for Cancel. Often used for warnings!

let leaveSite = confirm("You have unsaved changes. Are you sure you want to leave?");

if (leaveSite) {
    console.log("Leaving website...");
} else {
    console.log("Staying on page.");
}

Use Cases

When & Why to use them?

1. alert()

When: Displaying critical errors, warnings, or simple notifications.
Why: It guarantees the user sees the message because it pauses all page interactions until dismissed (e.g., "Form submitted successfully").

2. prompt()

When: Capturing quick, simple text input from the user.
Why: It provides an immediate way to store user input into a variable without having to build a full HTML form (e.g., "Enter your player name").

3. confirm()

When: Verifying potentially dangerous or permanent actions.
Why: It forces the user to make a binary decision (OK vs Cancel), acting as a safeguard to prevent accidental clicks (e.g., "Are you sure you want to delete this file?").

A. String Basics

Creation & Indexing

Creation

Strings can be created using Single Quotes '', Double Quotes "", or Backticks ``.

let a = "Hello"; let b = 'World'; let c = `!`;
Zero-Based Indexing & Length

Strings are indexed starting from 0. The .length property gives the total number of characters.

let str = "JavaScript";
console.log(str.length); // 10
console.log(str[0]);     // "J" (First character)
console.log(str[4]);     // "S"
console.log(str[100]);   // undefined (Invalid index)

B. Properties & Methods

Property vs Method

A Property is data (no parentheses). A Method is an action (requires parentheses ()).

Methods Without Arguments

Some methods just perform an action without needing extra data.

let text = "   Hello World!   ";

console.log(text.toUpperCase()); // "   HELLO WORLD!   "
console.log(text.toLowerCase()); // "   hello world!   "

console.log(text.trim());      // "Hello World!" (Removes spaces from BOTH ends)
console.log(text.trimStart()); // "Hello World!   " (Removes spaces from START)
console.log(text.trimEnd());   // "   Hello World!" (Removes spaces from END)

B. Properties & Methods

Method Chaining & Arguments

Method Chaining

You can run multiple methods back-to-back in a single line!

let input = "   jAvAsCrIpT   ";

// Standard way
let trimmed = input.trim();
let cleaned = trimmed.toLowerCase();

// Method Chaining (Better way)
let result = input.trim().toLowerCase(); 
console.log(result); // "javascript"
Arguments

Many methods require arguments (data inside the parentheses) to tell them what to do.

C. Searching Strings

includes() & indexOf()

includes()

Returns true if a string contains a specific word. It is case-sensitive!

let sentence = "I love JavaScript!";
console.log(sentence.includes("love")); // true
console.log(sentence.includes("Love")); // false (Case matters!)
indexOf()

Returns the index of the first occurrence of a substring. Returns -1 if not found.

console.log(sentence.indexOf("JavaScript")); // 7
console.log(sentence.indexOf("Python"));     // -1 (Not found)

D. Modifying Strings

Replace & Immutability

replace() & replaceAll() 
let quote = "Dogs are great. I love Dogs!";
console.log(quote.replace("Dogs", "Cats"));    // "Cats are great. I love Dogs!" (Only first)
console.log(quote.replaceAll("Dogs", "Cats")); // "Cats are great. I love Cats!" (All)
String Immutability

Strings are immutable! Methods return new strings, they DO NOT change the original.

let name = "Alice";
name.toUpperCase(); // Creates a new string, but we didn't save it!
console.log(name);  // "Alice" (Original is unchanged)
concat() vs +

Both join strings together. `+` is much more common than `concat()`.

console.log("Hello".concat(" ", "World")); // "Hello World"
console.log("Hello" + " " + "World");      // "Hello World"

E. Formatting Strings

Padding & Masking

padStart() and padEnd() add characters to a string until it reaches a desired length.

padStart(targetLength, padString) 
let str = "5";
console.log(str.padStart(3, "0")); // "005"
console.log(str.padEnd(3, "0"));   // "500"
Practical Use Case: Account Masking 
let accountNum = "123456781234";

// 1. Get the last 4 digits using slice
let lastFour = accountNum.slice(-4); // "1234"

// 2. Pad the start with "*" until it reaches the original length
let masked = lastFour.padStart(accountNum.length, "*"); 

console.log(masked); // "********1234"

F & G. Advanced Operations

Characters & Arrays

charAt() & charCodeAt()

charAt() is an older alternative to bracket notation []. charCodeAt() returns the ASCII integer code of a character.

let letter = "A";
console.log(letter.charAt(0));     // "A" (Same as letter[0])
console.log(letter.charCodeAt(0)); // 65 (The ASCII code for 'A')
String to Array: split()

Splits a string into an Array based on a separator (delimiter).

let names = "Alice,Bob,Charlie";
console.log(names.split(",")); // ["Alice", "Bob", "Charlie"]

let text = "Hello World";
console.log(text.split(" "));  // ["Hello", "World"] (Split by spaces)
console.log(text.split(""));   // ["H", "e", "l", "l", "o", " ", "W", "o", "r", "l", "d"]

H. Template Literals

The ES6 Revolution

Introduced in ES6 (ES2015), Template Literals use Backticks ` ` and are far superior to `+` concatenation.

String Interpolation & Expressions

You can dynamically inject variables and evaluate math expressions directly inside ${}.

let item = "Apples"; // Dynamic value
let price = 2;
let qty = 3;

// Old Way (Hard to read, easy to miss a space)
let msg1 = "You bought " + qty + " " + item + " for $" + (price * qty) + ".";

// New Way (Clean, dynamic, and evaluates expressions!)
let msg2 = `You bought ${qty} ${item} for $${price * qty}.`;
Multi-line Strings

Template literals inherently support multi-line strings without needing `\n`.

let email = `Dear Alice,
Thank you for joining.
Best,
The Team`;

Numbers & Math

Mathematical Operators

JavaScript uses standard math operators. Some might look new!

let a = 10;
let b = 3;

console.log(a + b); // 13 (Addition)
console.log(a - b); // 7  (Subtraction)
console.log(a * b); // 30 (Multiplication)
console.log(a / b); // 3.3333333333333335 (Division)

// Exponentiation (a to the power of b)
console.log(a ** b); // 1000 (10 * 10 * 10)

// Remainder (Modulo) - Returns the leftover after division
console.log(a % b); // 1 (10 divided by 3 is 9, remainder 1)

Numbers & Math

The Math Object

JavaScript has a built-in object called Math that provides properties and methods for mathematical constants and functions.

Math Constants (Properties) 
// Notice there are NO parentheses because these are Properties (Data)
console.log(Math.PI);      // 3.141592653589793
console.log(Math.E);       // 2.718281828459045 (Euler's Number)
console.log(Math.LN2);     // 0.6931471805599453 (Natural log of 2)
console.log(Math.SQRT2);   // 1.4142135623730951 (Square root of 2)
console.log(Math.SQRT1_2); // 0.7071067811865476 (Square root of 1/2)

Numbers & Math

Math Methods

Utility Methods 
console.log(Math.sqrt(64)); // 8 (Square Root)
console.log(Math.pow(2, 3)); // 8 (2 to the power of 3) - Same as 2 ** 3
console.log(Math.abs(-50)); // 50 (Absolute value)
Rounding Methods 
let num = 4.7;

console.log(Math.floor(num)); // 4 (Rounds DOWN to nearest integer)
console.log(Math.ceil(num));  // 5 (Rounds UP to nearest integer)
console.log(Math.round(num)); // 5 (Rounds to NEAREST integer)
console.log(Math.round(4.4)); // 4

Numbers & Math

Random Numbers

Math.random() generates a decimal number between 0 (inclusive) and 1 (exclusive).

console.log(Math.random()); // e.g., 0.123456789...
Generating Integer Ranges

Combine Math.random() with multiplication and Math.floor() to get usable integers.

// 1. Multiply by Max Number (e.g., 10)
let randomDecimal = Math.random() * 10; // 0.000 to 9.999

// 2. Chop off the decimals using floor
let randomInt = Math.floor(randomDecimal); // 0 to 9

// 3. (Optional) Add 1 if you want 1 to 10 instead of 0 to 9
let finalNum = randomInt + 1; // 1 to 10

// All in one line:
let diceRoll = Math.floor(Math.random() * 6) + 1; // 1 to 6

Numbers & Math

Special Number Values

Infinity & -Infinity

JavaScript does not crash if you divide by zero!

console.log(10 / 0);  // Infinity
console.log(-10 / 0); // -Infinity
console.log(typeof Infinity); // "number"
NaN (Not a Number)

Occurs when you try to do math with something that isn't a number.

console.log("Apples" / 2); // NaN (Not a Number)

// The funny quirk of JavaScript:
console.log(typeof NaN); // "number" 
// (It literally means "Invalid Number", so the type is still number!)

Numbers & Math

User Input & Coercion

prompt() ALWAYS returns a String 
let age = prompt("Enter age:"); // User types 25
// age is NOT the number 25. It is the string "25".
Automatic Type Coercion

JS tries to be helpful, but the + operator prioritizes String Concatenation!

console.log("10" - 2); // 8  (JS converts "10" to a number for subtraction)
console.log("10" * 2); // 20 
console.log("10" + 2); // "102" (DANGER! Uses concatenation instead of addition)
Explicit Conversion 
let num = Number("10"); // Converts string "10" to number 10
console.log(num + 2);   // 12 (Correct addition)

Numbers & Math

Practical Calculation

Putting it all together: Calculating Area & Perimeter.

// 1. Get input (Returns strings)
let lengthStr = prompt("Enter rectangle length:");
let widthStr = prompt("Enter rectangle width:");

// 2. Convert to Numbers explicitly!
let length = Number(lengthStr);
let width = Number(widthStr);

// 3. Calculate
let area = length * width;
let perimeter = 2 * (length + width); // Order of operations () applies!

// 4. Output
alert(`Area: ${area}, Perimeter: ${perimeter}`);

Displaying Results

Browser Output

document.write() vs console.log()

console.log() is for developers. document.write() writes directly to the webpage for the user to see!

document.write("<h1>Calculation Results</h1>");
document.write(`<p>The area is: ${area}</p>`);
The defer attribute warning

If your <script> tag has the defer attribute, document.write() will overwrite the entire page instead of appending to it. We will learn better ways to update the page later (DOM Manipulation).
